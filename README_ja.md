# Folder Size Guard Standalone 0.2.0 — プレビュー版

**Windhawk・.NET・Python・Visual Studioなどの追加インストールが不要な構成**に変更しました。コンパイル済みのEXEと同梱DLLだけで起動します。エクスプローラーの標準「サイズ」列への表示と容量順ソートを目的としています。

**Windows実機での表示・動作・安定性は未検証です。安定版ではありません。** 実施済みの検証は `TEST_REPORT.md` に記載しています。

## 起動手順

1. ZIPをローカルの固定ドライブへ展開します。使用中は展開先を移動・変更しないでください。
2. 旧版のFolder Size Guardや他の容量表示ModをWindhawkで有効にしている場合は、先に無効化します。旧版の `Install.cmd` を実行しただけなら、旧ワーカーを削除する必要はありません。
3. `Start.cmd` をダブルクリックします。自動で32bit／64bit版を選びます。64bit環境では `x64\FolderSizeGuard.exe` を直接起動しても構いません。
4. **「集計テスト」**を押します。新規の小さなテスト用ファイルで集計EXEを確認します。この時点ではエクスプローラーへ組み込みません。
5. エクスプローラーでコピー／移動などをしていない状態で、**「表示を開始」**を押します。最初だけシンボル情報を取得します。
6. エクスプローラーを「詳細」表示にして、F5を押します。集計が完了すると標準の「サイズ」列へ容量を返します。「サイズ」列をクリックして並べ替えます。集計後に並びが変わらなければ再クリックしてください。

使用中は専用画面を開いたままにします。最小化は可能です。エクスプローラーの新しいプロセスを後から開いた場合は、もう一度「表示を開始」を押してください。

管理者として実行する必要はありません。セキュリティ製品や組織のポリシーが組み込みを拒否した場合に、その保護を無効化・回避する機能はありません。

## 停止と元に戻す方法

- **「表示を停止」**を押すか、専用画面を閉じます。対象のエクスプローラーは強制終了しません。
- 停止後はエクスプローラーでF5を押してください。Shellの表示キャッシュに残った数値は更新まで見える場合があります。
- 停止後、組み込みDLLとフックの中継コードは、処理途中で取り外さないために休止状態で残ります。容量値への介入と集計を止め、標準処理へそのまま渡します。
- **完全にDLLを取り外す場合は、通常のサインアウト／サインインを行います。** 版の更新、展開先の移動、同梱DLLの削除も、その後に行ってください。

サービス、レジストリ、自動起動への登録は行いません。再ログイン後の自動再開も行いません。完全に取り外した後は展開フォルダーを手動で削除できます。アプリ専用キャッシュは `%LOCALAPPDATA%\FolderSizeGuard\standalone-v0.2` にあります。

## 「依存しない」の範囲

| 項目 | この版 |
|---|---|
| Windhawk / Everything | 不要 |
| .NET / Python / VC++再頒布パッケージ | 不要 |
| 利用者によるコンパイル | 不要 |
| 実行ファイル | Controller EXE・Bridge DLL・Worker EXEの3個を同梱 |
| Windows標準DLL | 使用。Win32 / WinHTTP / DbgHelp / Shell等 |
| フック処理のライブラリ | MinHook 1.3.4をソースから静的組み込み。別インストール・別DLL不要 |
| 初回・Windows更新後の通信 | Microsoftの公開シンボル情報をHTTPSで取得 |
| 通常の容量集計 | ネット通信不要。対象のメタデータだけを読み取り |

**初回から完全オフラインで動く構成ではありません。** Windows内部の関数を、固定アドレスの推測で書き換えないため、対応するMicrosoftのPDBシンボルを取得します。取得後は専用キャッシュを再利用します。Microsoftがシンボルを公開していないビルド、OS付属DbgHelpがPDBを読めない環境、必要な関数シグネチャが変わった環境では有効化を中止します。

通信に含めるのはWindowsのシステムDLLのシンボル名・GUID・ageです。集計対象のパス、ファイル名、内容を送信する機能はありません。WindowsシステムDLLをディスク上で変更しません。

## 対象ファイルの保護

集計ワーカーは `GetFileAttributesW`、`FindFirstFileExW`、`FindNextFileW` でディレクトリのメタデータを列挙します。ファイル本文を開く処理や、集計対象の削除・移動・リネーム・書き込み・属性変更・ACL変更・所有権取得を実装していません。結果は匿名パイプで返します。

ランチャーが作成するファイルは、アプリ専用領域のシンボルキャッシュと、「集計テスト」を押した場合の新規テストファイルです。既存のユーザーファイルをテストに使いません。ダウンロードの確定時だけ、新規キャッシュファイルを専用領域内でリネームします。途中で閉じた場合の `.part` ファイルやテスト用ファイルは自動削除せず残します。

集計はエクスプローラーとは別のプロセスです。1件ずつ実行し、優先度を抑え、128 MiBのメモリー上限と時間制限を設けています。タイムアウト／中止時に終了させるのは、このツールが生成した集計ワーカーだけです。エクスプローラーのスレッドを強制終了しません。ランチャーが終了した場合も、プロセス監視で集計を中止します。

Job Objectは資源制限であり、読み取り権限だけを与えるセキュリティサンドボックスではありません。ワーカーは通常のユーザー権限で動きます。

## 空欄になる条件

完全に列挙できたフォルダーだけを数値として返します。次を含む場合は、不完全な合計を確定値として表示しません。

- アクセス拒否、列挙エラー、タイムアウト、項目数などの上限超過。
- ジャンクション、シンボリックリンク、マウントポイント等の再解析ポイント。
- クラウドの再取得を示す属性、オフライン属性。
- 集計中、キュー上限、ワーカー起動失敗。

ネットワーク共有、ネットワークドライブ、リムーバブルドライブは対象外です。ルートまでの祖先に再解析ポイントがある場合も除外します。OneDriveでは取得済みでも表示されない場合があります。

**空欄は0バイトという意味ではありません。** 完全に列挙できた空フォルダーだけが0になります。昇順では数値がある項目を先に、不明な項目を後に比較します。降順では逆になります。ファイルとフォルダーは混在して比較します。

## 設定・容量の意味

展開フォルダーの `settings.ini` をメモ帳で編集できます。変更後は「表示を停止」、数秒待ってから「表示を開始」を押してください。

| 設定 | 既定値 | 有効範囲 |
|---|---:|---:|
| `TimeoutMs` | 5000 ms / フォルダー | 100〜30000 |
| `MaxEntries` | 1000000項目 / フォルダー | 1〜10000000 |
| `CacheSeconds` | 120秒 | 10〜600 |

失敗結果は60秒間再試行を抑制します。キャッシュは512パス、未集計キューは128パス、走査待機ディレクトリは1024件、深さは128段、集計パスは30000文字までです。ワーカーの親側タイムアウトには起動余裕1.5秒を加えます。Windows API自体の待ち時間を含めた厳密な応答時間の保証ではありません。

初回は実際のディレクトリ列挙が必要です。2回目以降は有効期限内のメモリーキャッシュを参照します。MFT直接解析や全ドライブの事前インデックスは使いません。SSD／HDDでの速度測定は未実施です。

常時変更監視は行いません。ファイル変更後も期限までは古い容量が見える場合があります。期限到達と集計完了でShellへ再表示通知を行います。F5だけでは有効期限内の独自キャッシュは消えません。即時再計算には「停止」→数秒待つ→「開始」を使用します。

表示は通常ファイルの**論理サイズの合計**です。物理的な「ディスク上のサイズ」ではありません。圧縮、スパース、代替ストリーム、ファイルシステム管理領域は加味しません。ハードリンクは名前ごとに加算します。走査中に別アプリが変更した場合の原子的なスナップショットではありません。

## 互換性・制限

Windows 10 x86/x64、Windows 11 x64を対象に設計しています。ARM64は対象外です。全ビルドでの実動作保証はありません。

標準のサイズ列への表示には、同一ユーザー・同一セッションの正規の `explorer.exe` へ同梱DLLを読み込み、Windows内部関数をメモリー上でフックします。インジェクション・フックを制限する環境では動作しません。プロセス名だけで他のアプリへ組み込む処理はなく、実行ファイルの場所と所有者も照合します。

DLLとPDBのGUID・age・イメージ情報、関数の完全なシグネチャ、実行可能領域内のアドレスを照合します。必須項目が欠けた場合は有効化しません。既存の一般的なフックが入口にある場合も中止します。ただし、内部関数の意味・ABIの変更や他の拡張との競合を完全に検出する仕組みではありません。Windows更新による表示不能、エクスプローラーのクラッシュの可能性は残ります。

データの読み取り専用設計と、エクスプローラーへ組み込むコードの安定性は別の問題です。現版は後者を実機で検証できていません。フックの開始・停止は、コピー／移動などの作業が終わってから行ってください。

実行ファイルはコード署名されていません。OSやセキュリティ製品による警告を自動解除する機能はありません。取得済みPDBが破損していた場合は、有効化を中止します。キャッシュの自動上書き・自動削除は行いません。
