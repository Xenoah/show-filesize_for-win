# show-filesize_for-win / Folder Size Guard

Windows 10/11の標準エクスプローラーに、フォルダー容量を表示・容量順にソートするためのネイティブツールです。

**現在は v0.2.0 Standalone Preview です。Windows実機での表示・安定性は未検証で、安定版ではありません。**

Windhawk・Everything・.NET・Python・VC++再頒布パッケージの追加インストール、利用者によるコンパイルは不要です。x86/x64のビルド済みEXEとDLLを同梱しています。

## ダウンロードと起動

1. [ZIPをダウンロード](https://github.com/Xenoah/show-filesize_for-win/archive/refs/heads/main.zip)して、ローカルの固定ドライブへ展開します。
2. 他のフォルダー容量表示Modを使用している場合は、先に無効化します。
3. `Start.cmd`を起動し、まず**「集計テスト」**を実行します。
4. コピー／移動などの作業が終わってから**「表示を開始」**を押します。
5. エクスプローラーを「詳細」表示にしてF5を押します。

初回・Windows更新後には、対応するMicrosoftの公開シンボルをHTTPSで取得します。初回から完全オフラインでは動きません。使用中は専用画面を開いたままにします。

## 設計と制限

- 集計対象のメタデータだけを読み取り、対象ファイルの削除・移動・書き込み・属性変更を行いません。
- 集計は別プロセスで実行し、時間・項目数・メモリーに上限を設けています。
- 不完全な集計結果を確定値として表示しません。ネットワーク／リムーバブルドライブ、再解析ポイントなどは対象外です。
- 標準のサイズ列へ組み込むため、Explorer内の非公開関数をフックします。Windows更新や他の拡張との競合による表示不能・クラッシュの可能性は残ります。
- 停止ボタンまたは専用画面を閉じると集計と容量値への介入を停止します。DLLの完全な取り外しには通常のサインアウト／サインインが必要です。
- サービス・レジストリ・自動起動への登録はありません。ARM64は対象外です。

## 開発

`src/`にソース、`tests/`に集計ロジック等のテスト、`vendor/minhook/`に静的組み込みライブラリを収録しています。MinGW-w64のクロスコンパイラを使うLinux環境で、`bash build.sh`によりx86/x64を再ビルドできます。

アプリ部分はGPL-3.0-onlyです。MinHook等のライセンスはそれぞれの同梱文書を参照してください。
